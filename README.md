# Тележка 🛒

Неофициальный клиент Telegram для Android. Сама находит рабочее подключение, когда Telegram плохо грузится, а ещё умеет то, чего нет в обычном приложении.

**[⬇️ Скачать последнюю версию](https://github.com/telesga/tg-proxy/releases/latest)** · новости в канале [@teleskaoff](https://t.me/teleskaoff)

## Что умеет

- **Автоподбор прокси.** Тележка сама проверяет прокси, включает самый быстрый и переключается, если он перестал работать. Список обновляется каждые 30 минут.
- **Скрытые чаты.** Любой чат можно спрятать из списка под PIN-код.
- **Удалённые сообщения остаются.** Если собеседник удалил сообщение, у вас оно сохранится.
- **Голосовые в текст.** Бесплатная расшифровка голосовых сообщений (голосовое для этого отправляется на сервер Тележки).
- **Музыка.** Поиск треков, любимые треки и популярное прямо в приложении.
- **Обновления внутри приложения.** Когда выходит новая версия, Тележка сама предложит её поставить.

## Как установить

1. Откройте [страницу последней версии](https://github.com/telesga/tg-proxy/releases/latest) с телефона.
2. Скачайте файл `.apk` и откройте его.
3. Если Android спросит, разрешите установку из этого источника.

Нужен Android на 64-битном процессоре (почти все телефоны последних лет).

## Важно

Тележка — неофициальное приложение, она не связана с Telegram. Аккаунт и переписка работают через обычные серверы Telegram.

---

### Для разработчиков

Тележка собрана на основе [официального исходного кода Telegram для Android](https://github.com/DrKLO/Telegram) и распространяется под той же лицензией GPL v2 (см. [LICENSE](LICENSE)). APK собирает GitHub Actions при каждом коммите в `main` и выкладывает в Releases. Для своей сборки нужны собственные `api_id`/`api_hash` с [my.telegram.org](https://my.telegram.org) — в репозитории они берутся из секретов `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.
