# TG Proxy: Telegram с автоподбором прокси

Это форк официального [Telegram для Android](https://github.com/DrKLO/Telegram).
Добавлен экран **«Подобрать прокси»**: приложение скачивает список прокси с вашего сервера,
проверяет их прямо на телефоне и включает самый быстрый. Остальные рабочие сохраняются как запасные.

Приложение ставится **рядом** с обычным Telegram (у него своё имя пакета `org.proxypicker.messenger`
и название «TG Proxy»).

Где найти кнопку:

- на самом первом экране (до входа в аккаунт): «Подобрать прокси» в левом верхнем углу;
- в Настройки → Данные и память → Прокси: пункт «Подобрать прокси автоматически».

---

## Шаг 1. Получите свои API-ключи Telegram (5 минут, один раз)

Правила Telegram требуют, чтобы у каждого стороннего клиента были свои ключи.
Без них сборка остановится с понятной ошибкой.

1. Откройте https://my.telegram.org и войдите по номеру телефона (код придёт в Telegram).
2. Нажмите **API development tools**.
3. Заполните форму: *App title* — например `TG Proxy`, *Short name* — `tgproxy`, *Platform* — **Android**. Остальное можно не трогать.
4. Нажмите **Create application**.
5. Скопируйте два значения: **App api_id** (число) и **App api_hash** (32 символа). Никому их не показывайте.

## Шаг 2. Добавьте ключи в GitHub

1. Откройте свой репозиторий на GitHub.
2. Вверху нажмите **Settings** (шестерёнка).
3. Слева: **Secrets and variables** → **Actions**.
4. Вкладка **Secrets** → зелёная кнопка **New repository secret**:
   - Name: `TELEGRAM_API_ID`, Secret: ваш api_id → **Add secret**.
5. Ещё раз **New repository secret**:
   - Name: `TELEGRAM_API_HASH`, Secret: ваш api_hash → **Add secret**.

## Шаг 3. Укажите адрес своего списка прокси

1. Там же (**Secrets and variables** → **Actions**) откройте вкладку **Variables**.
2. **New repository variable**:
   - Name: `PROXY_LIST_URL`
   - Value: адрес вашего файла, например `https://my-server.ru/proxies.json`
3. **Add variable**.

Если переменную не создать, в приложении останется заглушка `https://example.com/proxies.json`,
и подбор будет работать только по встроенному запасному списку (см. ниже).

Формат файла на сервере — JSON-массив (пример: [`docs/proxies.example.json`](docs/proxies.example.json)):

```json
[
  {"server": "1.2.3.4", "port": 443, "secret": "ee0123456789abcdef0123456789abcdef6578616d706c652e636f6d"},
  {"server": "proxy.example.org", "port": 8443, "secret": "dd0123456789abcdef0123456789abcdef"}
]
```

Приложение отбрасывает мусор: неверный порт (не 1–65535), secret не из hex-символов
или неразумной длины, дубли. Берёт не больше 100 прокси.

## Шаг 4. Соберите APK

1. В репозитории нажмите вкладку **Actions**.
2. Если GitHub спросит — нажмите **I understand my workflows, go ahead and enable them**.
3. Слева выберите **Build APK**.
4. Справа кнопка **Run workflow** → ещё раз зелёная **Run workflow**.
5. Ждите. Первая сборка идёт **около 1–2 часов** (компилируется много нативного кода). Жёлтый кружок — идёт, зелёная галочка — готово, красный крестик — ошибка.

Сборка также запускается сама при каждом изменении файлов в репозитории.

## Шаг 5. Установите на телефон

1. На телефоне откройте страницу репозитория на GitHub → раздел **Releases** (справа на странице, или добавьте `/releases` к адресу).
2. В последней сборке («Сборка N») нажмите на файл `TG-Proxy-N.apk` — он скачается.
3. Откройте скачанный файл. Android попросит разрешить установку из этого источника — разрешите.
4. Нажмите **Установить**.

Обновление: соберите заново и установите новый APK поверх старого — данные сохранятся.

## Как работает подбор

1. Скачивается список с `PROXY_LIST_URL` (таймаут 10 секунд, не больше 1 МБ).
2. Если сервер недоступен или список пуст — берётся встроенный запасной список.
3. Прокси проверяются встроенной проверкой Telegram по 12 одновременно, таймаут 7 секунд на каждый.
   На экране: «Проверено X из Y, рабочих Z».
4. Самый быстрый включается, остальные рабочие сохраняются в список прокси как запасные.
5. Особый случай — **первый запуск, когда Telegram заблокирован**. Встроенная проверка Telegram
   не может работать без первого соединения с серверами. Тогда приложение проверяет, отвечают ли
   прокси вообще, и по очереди (до 5 штук) пробует реально подключиться через самые быстрые.

> Прокси публичные, их владельцы видят ваш IP.

## Встроенный запасной список

Файл `TMessagesProj/src/main/java/org/telegram/ui/ProxyPickerActivity.java`, массив `FALLBACK_PROXIES`
в начале класса. Отредактировать можно прямо на сайте GitHub: откройте файл → значок карандаша → впишите строки вида

```java
    private static final String[][] FALLBACK_PROXIES = {
            {"1.2.3.4", "443", "ee0123456789abcdef0123456789abcdef6578616d706c652e636f6d"},
            {"5.6.7.8", "8443", "dd0123456789abcdef0123456789abcdef"},
    };
```

→ **Commit changes**. Сборка запустится сама.

## Что изменено относительно официального Telegram

| Файл | Что сделано |
|---|---|
| `ui/ProxyPickerActivity.java` | новый экран подбора прокси |
| `ui/IntroActivity.java` | кнопка «Подобрать прокси» на первом экране |
| `ui/ProxyListActivity.java` | пункт «Подобрать прокси автоматически» в настройках прокси |
| `messenger/BuildVars.java` | константа `PROXY_LIST_URL`; passkeys выключены (работают только в официальном приложении) |
| `jni/tgnet/Defines.h` | одновременных проверок прокси 12 вместо 4 |
| `res/values/strings.xml` | тексты экрана; название приложения «TG Proxy» |
| `gradle.properties`, `TMessagesProj_App/google-services.json` | своё имя пакета, чтобы ставилось рядом с Telegram |
| `.github/workflows/build.yml` | сборка APK в GitHub Actions |

## Если сборка упала

- **«Add TELEGRAM_API_ID and TELEGRAM_API_HASH secrets»** — не выполнен шаг 2, или имя секрета написано с ошибкой.
- **Другая красная ошибка** — откройте упавшую сборку → шаг с крестиком → скопируйте последние 50–100 строк лога и пришлите тому, кто помогает.

## Ограничения

- Push-уведомления через Google (Firebase) в форке не работают: они привязаны к официальному приложению.
  Сообщения приходят, пока приложение запущено или висит в фоне.
- APK подписан тестовым ключом из исходников Telegram (он публичный). Для личного использования это нормально.
